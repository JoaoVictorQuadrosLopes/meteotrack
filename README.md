Objetivo do projeto: Centralizar informações meteorológicas em uma aplicação web permetindo monitorar diferentes localidades e também estações físicas.
 O sistema trabalha com duas fontes de dados: API para cidades externas e Arduino para estações locais


 PRINCIPAIS FUNCIONALIDADES:
 - Autenticar com firebase
 - Cadastro de locais monitorados
 - Buscar clima por cidade
 - Registro de dados da cidade
 - Integração com estação local
 - Coleta automatica de dados 
 - Filtros
 - Analises com gráficos
 - Relatorio em PDF e CSV
 - Controle de dados por usuario
